#  KLYMO — AI Prompt Generator (QA Portfolio Project)
This is a **junior QA testing project** for the frontend web application **KLYMO**, a simple AI prompt generator.
The purpose of this repository is to **practice and showcase testing skills**.
---
##  Project Overview
- A lightweight frontend website that allows users to generate prompts for AI.
- Works mainly in Ukrainian, but English and Russian are partially supported.
- Pure frontend — no backend.
- Intended for QA testing practice and portfolio.
---
##  Features to Test
- UI elements: buttons, input fields, copy-to-clipboard.
- Multi-language support (UA / EN / RU).
- Responsiveness on different screen sizes.
- Basic usability and functionality of the prompt generator.
- Error handling (if invalid input or empty fields).
