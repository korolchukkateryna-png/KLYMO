## TC304

**Title:** Verify form behaviour when JavaScript is disabled

**Precondition:**
User disables JavaScript in the browser.

**Test Steps:**

1. Disable JavaScript in the browser settings.
2. Open the website.
3. Navigate to the lead form.
4. Attempt to fill in all fields.
5. Click **"Надіслати"**.

**Expected Result:**
The system should either still process the form correctly or display an appropriate message indicating that JavaScript is required.

**Priority:** Medium
